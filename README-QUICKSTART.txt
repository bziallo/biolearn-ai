BioLearn AI V1.0 便携版 —— 快速使用说明
=========================================

本目录是免安装版本，不需要你自己安装 Python，也不需要联网安装依赖。

一、首次启动
------------
1. 双击 BioLearnAI.cmd（或 start.bat）。
2. 稍等几秒，浏览器会自动打开 http://127.0.0.1:8000/
3. 首次运行会自动创建 data\ 目录、初始化数据库并写入 db。

二、AI 功能（可选）
------------------
- 打开左侧导航“AI 设置”，填写 API Base、API Key、模型名称。
- 密钥只保存在本机 data\ai_config.json，不会上传到任何地方。
- 不配置 AI 也能使用：导入、知识点审核、题库、练习全部可用，只是不能自动识别和出题。

三、停止
--------
- 关闭启动窗口，或双击 stop.bat。

四、数据位置与备份
------------------
- 数据都在本目录的 data\ 文件夹（biolearn.db、uploads、ai_config.json）。
- 备份：双击 backup.bat，或手动复制整个 data\ 文件夹。
- 恢复：先 stop.bat，再双击 restore.bat 并选择备份目录。
- 升级：直接把新版本的 app\、frontend\ 覆盖进来；启动时会自动检测并
  在 data\pre_migration_backups\ 先备份再迁移，不会清空已有数据。

五、常见问题
------------
- 提示端口 8000 被占用：说明可能已经启动过一次，先看看浏览器是否已打开；
  或运行 stop.bat 后再启动。
- 想换端口：打开 .env，把 PORT 改掉，同时修改 start.bat 里的 PORT 值。
- 想换数据目录：编辑 .env 的 DATABASE_URL 与 UPLOAD_DIR（相对路径以
  backend 目录为基准，便携版中即本目录下的 data）。
- 页面打不开：确认窗口没有报错；日志在 data\logs\。

六、卸载
--------
- 直接删除本目录即可。若要保留数据，先备份 data\ 文件夹。
